# Система команд

## Легенда

- **OP** - код операции.
- **SF** - суффикс (режим).
- **InsType** - формат инструкции (см. [форматы](instruction-formats.md)).
- **FlMask** - маска флагов, которые изменяет инструкция (`*` - не изменяется).
- **Description** - описание.
