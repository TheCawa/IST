# Процессор I8046

## Общее описание

**I8046** это 24-битный процессор, разрабатывавшийся в рамках проекта **i48**. Он стал развитием идей I80148, но получил более богатую систему команд, расширенное адресное пространство и поддержку сегментной адресации.

Несмотря на то, что работа над процессором была остановлена, его архитектура представляет интерес как пример удачного баланса между простотой и функциональностью.

## Ключевые характеристики

| Параметр | Значение |
|----------|----------|
| Разрядность данных | 24 бит |
| Адресное пространство | до 16 МБ (24-битная шина адреса) |
| Регистры общего назначения | 5 × 24-битных (X1–X5) |
| Специальные регистры | IX, IY, SP, BP, A0, A1, FL, IC |
| Сегментные регистры | CS, DS, SS, ES + теневые SCS, SDS, SSS, SES |
| Система команд | ~40 инструкций, 24 формата |
| Флаги | 8 бит (C, B, S, O, Z, G, E, L) |
