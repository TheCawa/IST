# Микрокод и PLA

## PLA-таблицы

| Файл | Назначение | Формат |
|------|------------|--------|
| `CU_PLA.txt` | Основное управляющее устройство | `16-битный вход` → `36-битный выход` |
| `MICROCODE_PLA.txt` | Упрощённая таблица микрокода | `16-битный вход` → `16-битный выход` |
| `LENGHT_PLA.txt` | Длины инструкций | `5-битный вход` → `4-битный выход` |
| `ALU_PLA.txt` | Операции АЛУ/BSU | `8-битный вход` → `4-битный выход` |

## Формат входа

Вход у `CU_PLA` и `MICROCODE_PLA` формируется из двух полей:

```text
IN:
        OP      SF
     ╒══════╕╒══════╕
FF < XXXXXXXXXXXXXXXX < 00
```

- **OP** - opcode (8 бит).
- **SF** - суффикс / режим (8 бит).

## Выход CU_PLA

`CU_PLA` выдаёт 36-битный управляющий вектор. Пример:

```text
0000001100000000 000000000010000000000000010000000100 # ADD
```

Здесь вход - `03h 00h`, выход - 36-битный вектор микрокоманд.

## MICROCODE_PLA

Упрощённая версия с 16-битным выходом. Формат полей:

```text
OUT:
      IT     FM    MD
     ╒═══╕╒══════╕╒═╕
FF < XXXXXXXXXXXXXXXX < 00
```

- **IT** - Instruction Type (5 бит, формат инструкции).
- **FM** - Flag Mask (8 бит, маска флагов).
- **MD** - Mode (3 бита, режим доступа).
