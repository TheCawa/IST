| `1Bh` | D3SD | 6B | `<OP> <SF> <rD> <rB>:<rA> <disp8>` |
| `1Ch` | D3RD | 5B | `<OP> <SF> <rD> <rA> <disp8>` |

## Пояснения к обозначениям

- `<OP>` - код операции (opcode).
- `<SF>` - суффикс / режим (byte, word, dword, register).
- `<rD>` - регистр-приёмник (destination).
- `<rS>` - регистр-источник (source).
- `<rS/D>` - регистр, который может быть и источником, и приёмником.
- `<rA>`, `<rB>` - регистры базы и индекса.
- `<imm8>`, `<imm16>`, `<imm32>` - непосредственные значения.
- `<Addr32>` - абсолютный 32-битный адрес.
- `<disp8>` - 8-битное смещение.
- `<COND>` - код условия перехода.

## Длина инструкции

Длина закодирована в PLA-таблице `LENGHT_PLA`. Выходное значение - это `длина − 1`:

| Выход | Длина |
|-------|-------|
| `0000` | 1 байт |
| `0001` | 2 байта |
| `0010` | 3 байта |
| `0011` | 4 байта |
| `0100` | 5 байт |
| `0101` | 6 байт |
| `0110` | 7 байт |
