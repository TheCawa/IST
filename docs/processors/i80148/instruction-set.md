# Система команд

## Легенда

- **OP** - код операции.
- **SF** - суффикс (режим).
- **InsType** - формат инструкции (см. [форматы](instruction-formats.md)).
- **FlMask** - маска изменяемых флагов (см. [флаги](flags.md)).
- **Description** - краткое описание.

## Группы инструкций

- **Управление:** NOP, HALT, WAIT.
- **Арифметика:** ADD, ADC, SUB, SBB, MUL, IMUL, DIV, IDIV, REM, IREM, INC, DEC.
- **Логика:** AND, OR, XOR, NOT.
- **Сдвиги:** LSL, LSR, ASR, ROL, ROR.
- **Сравнение:** CMP, ICMP.
- **Переходы:** JMP, JMPR, JMA, CALL, CALLR, CLABS, RET.
- **Память:** COPY, LDI, STR, LOD.
- **Стек:** PUSH, POP.
- **Прерывания:** INT, IRET, CLI, STI.
