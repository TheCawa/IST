# Процессор I80148

## Общее описание

**I80148** 32-битный процессор с flat-моделью памяти, работающий в режиме **Big Endian**. Это первая полноценная реализация архитектуры i48, ставшая базой для всего проекта.

Процессор имеет 36 регистров, включая 21 регистр общего назначения (три набора по 7 регистров разной разрядности), 8 адресных регистров, регистры индексации, стековые регистры и регистр таблицы дескрипторов прерываний (IDTR).

## Ключевые характеристики

| Параметр | Значение |
|----------|----------|
| Порядок байтов | **Big Endian** |
| Разрядность данных | 32 бита |
| Шина адреса данных | 32 бита (4 ГБ) |
| Шина адреса инструкций | 32 бита (4 ГБ) |
| Шина входных данных | 32 бита (4 байта) |
| Шина выходных данных | 32 бита (4 байта) |
| Шина инструкций | 64 бита (8 байт) |
| Модель памяти | Flat |
| Количество регистров | 36 |
| Регистров общего назначения | 21 (EX1–EX7, X1–X7, XL1–XL7) |
| Адресных регистров | 8 (A0–A7) |
| Система команд | ~45 инструкций |
| Флаги | 8 бит (C, B, S, O, Z, G, E, L) |

## Режимы адресации памяти

- **Flat** - абсолютный 32-битный адрес (`imm32`).
- **Index** - адрес по базе и смещению (`Base:Offset`).
- **Indirect** - косвенная адресация через регистр (`reg`).
- **Index-disp** - база, смещение и дисплейсмент (`Base:Offset:disp`).
- **Indirect-disp** - регистр и дисплейсмент (`reg:disp`).

## Режимы адресации инструкций

- **Flag** - абсолютный адрес (`IC = imm32`).
- **Relative** - относительно счётчика инструкций (`IC + imm32`).
- **Indirect** - через регистр (`IC = reg`).
