# Начало работы

Этот раздел поможет быстро познакомиться с проектом **IST** и запустить первую программу на процессоре **i80148**.

## С чего начать

1. **[Установка](installation.md)** - что нужно для сборки и запуска: Python, зависимости, клонирование репозитория.
2. **[Быстрый старт](quick-start.md)** - соберём простую программу «Hello, World!» и запустим её в эмуляторе.

## Что понадобится

Для работы с проектом нужны только **Python 3** и **Git**. Все инструменты (ассемблер, линкер, архиватор) - это обычные Python-скрипты, дополнительных системных пакетов не требуется.
