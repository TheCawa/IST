# Установка

## Требования

Для работы с проектом нужны:

| Компонент | Версия | Зачем |
|-----------|--------|-------|
| **Python** | 3.8+ | Ассемблер, линкер, архиватор, эмулятор |
| **Git** | любая | Клонирование репозитория |

## Клонирование репозитория

```bash
git clone https://github.com/TheCawa/IST.git
cd IST
```

## Проверка установки

Убедись, что ассемблер запускается и выводит справку:

```bash
python CASM148.py
```

Если всё установлено верно, ты увидишь сообщение об использовании:

```text
Usage: python CASM148.py [-c] [--obj-format binary|json] <input.asm> [-o output.bin]
```
