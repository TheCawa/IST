# CASM

**CASM** (Cawas Assembler) - семейство ассемблеров для процессоров архитектуры i48.

## Доступные версии

| Инструмент | Целевой процессор | Статус |
|------------|-------------------|--------|
| [CASM46](casm46.md) | i8046 | Архивный (процессор заморожен) |
| [CASM148](casm148.md) | i80148 | Активный |
