# Инструменты

В этом разделе собрана документация по инструментальной цепочке проекта **i48**. Все инструменты написаны на Python, работают с Big Endian и ориентированы на архитектуру **i80148**.

## Состав тулчейна

| Категория | Инструмент | Назначение |
|-----------|------------|------------|
| **CASM** | [CASM46](casm/casm46.md) | Ассемблер для i8046 |
| **CASM** | [CASM148](casm/casm148.md) | Ассемблер для i80148 |
| **DISCASM** | [DISCASM148](discasm/discasm148.md) | Дизассемблер для i80148 |
| **LINK** | [LINK148](link/link148.md) | Компоновщик объектных файлов i80148 |
| **AR** | [AR148](ar/ar148.md) | Архиватор статических библиотек |
