    CASM46¶

    CASM46 (Cawas Assembler for i8046) - ассемблер для процессора i8046. Работает с 24-битным кодом Big Endian и сразу выдаёт плоский бинарник.

    Параметр Значение
    Целевой процессор i8046 (24 бита)
    Порядок байтов Big Endian
    Формат вывода .bin + .hex
    Язык Python 3
    Файл CASM46.py
    Статус Архивный (I8046 заморожен)

    Использование¶

    python CASM46.py program.asm -o program.bin

    Опции:

    Опция Описание
    -o file Имя выходного файла (по умолчанию output.hex)

    На выходе получаются два файла: output.hex (Logisim v2.0 raw) и output.bin (сырой бинарник).

    Синтаксис¶

    • Комментарии - ;.
    • Метки - идентификатор с :.
    • Сегменты .TEXT, .DATA, .RODATA, .BSS поддерживаются, но сливаются в один поток (объектный режим отсутствует).
    • Директивы .ORG, .DB, .DW, .DD, .DA (24-битные адреса).

    Регистры¶

    Имя Адрес Имя Адрес
    R0 00h IX 10h
    X1 01h IY 11h

    Система команд¶

    Полный список - в разделе Система команд i8046. Кратко:

    • Арифметика: ADD, ADC, SUB, SBB, MUL, IMUL, DIV, IDIV.
    • Логика: AND, OR, XOR, NOT, INC, DEC, LSL, LSR, ASR, ROL, ROR.
    • Сравнение: CMP, ICMP.
    • Переходы: JMP (с условиями .C, .Z, .NZ, .GR, .GE, .LS, .LE, .EQ, .NE и т.д.).
    • Память: MOV, LDI.b/w/a, STR.b/w/a, LOD.b/w/a.
    • Стек: PUSH, POP, CALL, RET.
    • Система: NOP, HALT, CLI, STI, INT, IRET, WRINT, LOCK, UNLOCK.

    Адресация STR/LOD¶

    Ассемблер сам выбирает режим по синтаксису операнда:

    Режим Пример Формат
    Flat [0x00020018] D2F / D3F
    Segment [rB:rA] D2S / D3S
    Register [rA] D2R / D3R

    Пример¶

            .ORG 0x000000
        .TEXT
main:
        LDI.a A0, 0x00020110    ; DISK_STATUS
        LOD.b XL1, [A0]
        CMP.b XL1, 0
        JMP.NZ main
        HALT
