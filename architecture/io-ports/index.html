    I/O-порты¶

    Карта регистров¶

    Системные¶

    Индекс Адрес Доступ Имя Описание
    0000h 00020000h R SYS_STATUS Статус системы
    0001h 00020001h R/W SYS_CTRL Управление системой
    0002h 00020002h - IRQ_PEND Ожидающие прерывания
    0003h 00020003h - IRQ_MASK Маска прерываний
    0004h 00020004h R TIMER_LOW Младшая часть таймера
    0005h 00020005h R TIMER_HIGH Старшая часть таймера
    0006h 00020006h R UPTIME Время работы системы
    0007h 00020007h R/W BANK Селектор банка VRAM
    0008h 00020008h R/W KBD_CTRL Управление клавиатурой
    0009h 00020009h R KBD_SCANCODE Скан-код следующей клавиши (PC set-1)
    000Ah 0002000Ah R KBD_MODIFIER Зафиксированные модификаторы
    000Bh 0002000Bh R KBD_ASCII ASCII-код активной клавиши
    000Ch 0002000Ch R RAM_SIZE Размер ОЗУ
    0010h 00020010h R CPU_FEATURES Возможности CPU
    0011h 00020011h R/W BOOT_DEVICE Загрузочное устройство
    0012h 00020012h R/W SYS_FLAGS Системные флаги
    0013h 00020013h R ERROR_CODE Код последней ошибки

    Терминал и видео¶

    Индекс Адрес Доступ Имя Описание
    0018h 00020018h W TERM_OUT Вывод символа в терминал
    0019h 00020019h W TERM_COMMAND Команда терминала (см. ниже)
    001Ah 0002001Ah R/W VC_MODE Режим видеокарты
    001Bh 0002001Bh R/W TERM_ATTR Атрибут символа (младшие 16 = fg, старшие 16 = bg)
    0060h 00020060h R TERM_RES_X Ширина экрана (символы или пиксели)
    0064h 00020064h R TERM_RES_Y Высота экрана
    0068h 00020068h R/W TERM_POS_X Позиция курсора по X
    006Ch 0002006Ch R/W TERM_POS_Y Позиция курсора по Y
    0070h 00020070h R/W TERM_BUFFER Базовое смещение VRAM

    Команды TERM_COMMAND:

    Значение Команда
    01h Очистить экран
    02h Включить курсор
    03h Выключить курсор
    04h Включить прокрутку
    05h Выключить прокрутку

    Звукогенератор (PSG)¶

    Индекс Адрес Доступ Имя Описание
    00B0h 000200B0h R/W PSG_TONE0 Период тона канала 0 (16-бит)
    00B2h 000200B2h R/W PSG_TONE1 Период тона канала 1
    00B4h 000200B4h R/W PSG_TONE2 Период тона канала 2
    00B6h 000200B6h R/W PSG_NOISE Период шума
    00B7h 000200B7h R/W PSG_MIXER Микшер (bits 0-2 - тон, 3-5 - шум)
    00B8h 000200B8h R/W PSG_VOL0 Громкость канала 0 (4 бита) + бит 7 - огибающая
    00B9h 000200B9h R/W PSG_VOL1 Громкость канала 1
    00BAh 000200BAh R/W PSG_VOL2 Громкость канала 2
    00BBh 000200BBh R/W PSG_ENV_PERIOD Период огибающей (16-бит)
    00BDh 000200BDh R/W PSG_ENV_SHAPE Форма огибающей (см. ниже)
    00BEh 000200BEh R PSG_ENV_LEVEL Текущий уровень огибающей (0-15)

    XPB1 - дисковый контроллер¶

    Индекс Адрес Доступ Имя Описание
    0100h 00020110h R DISK_STATUS Статус
    0101h 00020111h R/W DISK_CTRL Управление (команды)
    0102h 00020112h R/W DISK_LBA Младшая часть LBA
    0103h 00020113h R/W DISK_LBA_HI Старшая часть LBA
    0104h 00020114h R/W DISK_BUFFER Буфер сектора
    0105h 00020115h R/W DISK_COUNT Число секторов
    0106h 00020116h R/W DISK_DRIVE Номер диска
    0107h 00020117h R/W DISK_IRQ IRQ
    0108h 00020118h R/W DISK_SIZE Размер диска
    0109h 00020119h R/W LBA_SIZE Размер LBA
    010Ah 0002011Ah R DISK_DOUT Вывод данных
    010Bh 0002011Bh R/W DISK_DIN Ввод данных
    010Ch 0002011Ch R/W BUFFER_OFFSET Смещение буфера

    Команды DISK_CTRL:

    Код Команда
    00h Idle / reset
    01h Acknowledge ready
    02h Read single sector
    03h Read multiple sectors
    04h Write single sector
    05h Write multiple sectors
    08h Write DISK_DIN в буфер по BUFFER_OFFSET
    10h Format (обнулить DISK_COUNT секторов начиная с DISK_LBA)

    Биты статуса DISK_STATUS:

    Бит Имя Описание
    0 BUSY Устройство занято
    1 ERROR Ошибка
